# In Scope
The **CardFlow Credit Origination Platform** supports the following functional areas within
the credit card origination lifecycle:

- **Credit Application Submission**
    - Applicant registration and authentication
    - Creation of new credit card applications
    - Enforcement of one active application per applicant
    - Pre-population of available customer data
    - Upload of supporting documentation
    - Validation of required fields prior to submission
    - Submission locking upon finalization
- **Multi-Level Review and Approval Workflow**
    - Configurable approval matrix based on defined thresholds
    - Routing of applications to reviewers and approvers
    - Support for manual reassignment where necessary
    - Return-to-applicant functionality for incomplete submissions
    - Mandatory comment capture for approval, rejection, or return actions
    - Automatic notification triggers at defined workflow stages
- **Credit Amendment / Update Process**
    - Initiation of update requests for approved applications
    - Restriction of updates when other active applications exist
    - Approval routing consistent with configurable workflow rules
    - Locking of records post-submission
- **Credit Reinstatement Process**
    - Initiation of reinstatement requests by authorized tenant users
    - Workflow routing based on configured approval hierarchy
    - Status tracking and notification upon decision
- **Document Management**
    - Support for predefined file formats (for example, PDF, JPG, PNG)
    - Enforcement of file size limits
    - Storage of uploaded documents linked to application records
    - Manual validation of document contents by authorized reviewers
- **Reporting and Audit Capabilities**
    - Application listing and filtering by status, date, and role
    - Export capability for reporting purposes
    - Capture of approval history and decision logs
    - Audit trail visibility for administrative users
- **Administrative Configuration**
    - Configuration of approval matrices
    - Management of requirement lists
    - Role configuration and permission management
    - Access to audit logs
    - System-level configuration controls

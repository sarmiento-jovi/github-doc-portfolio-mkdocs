    Common Validation Errors

    Validation errors occur when required information is missing, incomplete, or does not meet configured business rules.

    Required Information Missing

    The system displays a validation message indicating that mandatory fields have not been completed.

    Required Information Missing
    Possible Cause One or more required fields contain no value.
    Resolution 1. Review all highlighted fields.
    2. Enter the required information.
    3. Save or resubmit the request.

    Invalid Data Format

    The system rejects the entered value.

    Invalid Data Format
    Possible Cause The value does not match the expected format.

    Examples:
    • Invalid email address
    • Invalid phone number
    • Unsupported date format
    • Invalid identification number
    Resolution 1. Verify the entered value.
    2. Correct the format.
    3. Save or resubmit the request.

    Business Rule Validation Failure

    The application cannot proceed to the next workflow stage.

    Business Rule Validation Failure
    Possible Cause One or more configured business rules have not been satisfied.

    Examples:
    • Required supporting documents not uploaded
    • Eligibility criteria not met
    • Mandatory review activities incomplete
    Resolution 1. Review validation messages displayed by the system.
    2. Complete the missing requirements.
    3. Resubmit the application.

    Upload Failures

    The selected file cannot be uploaded. Document upload issues may prevent applications from being submitted or processed.

    Upload Failures
    Possible Cause • Unsupported file type
    • File exceeds maximum size limit
    • Network interruption during upload
    Resolution 1. Verify that the file type is supported.
    2. Confirm the file size complies with organizational requirements.
    3. Retry the upload.
    4. Refresh the page if necessary.

    Uploaded File Not Visible

    The uploaded document does not appear in the application.

    Uploaded File Not Visible
    Possible Cause • Upload process did not complete successfully
    • Browser session expired
    Resolution 1. Refresh the page.
    2. Verify that the document appears in the Supporting Documents section.
    3. Re-upload the document if required.

    Duplicate Document Upload

    The system prevents uploading a document that already exists.

    Resolution

    1. Review existing uploaded documents.
    2. Replace the existing file only if an updated version is required.

    Returned Requests

    Applications may be returned when additional information, clarification, or document updates are required. * Returned Requests
    Possible Cause A reviewer or approver identified missing information or documentation.
    Resolution 1. Open the returned application.
    2. Review the return comments.
    3. Complete the requested updates.
    4. Upload any required supporting documents.
    5. Resubmit the application.

    Unable to Resubmit Returned Request

    The application cannot be resubmitted. Unable to Resubmit Returned Request
    Possible Cause • Required corrections have not been completed
    • Mandatory fields remain incomplete
    • Required documents are missing
    Resolution 1. Review all validation messages.
    2. Complete outstanding requirements.
    3. Attempt resubmission again.

    Access Issues

    The system displays an access denied message. Access-related issues may occur when users do not have sufficient permissions or when authentication problems exist.

    Access Issues
    Possible Cause The user does not have permission to access the requested function or application.
    Resolution 1. Verify that you are assigned the appropriate role.
    2. Contact your administrator if additional permissions are required.

    Application Not Visible

    An expected application does not appear in search results.

    Application Not Visible
    Possible Cause • Application belongs to another tenant
    • User lacks access permissions
    • Search criteria are filtering results
    Resolution 1. Verify search filters.
    2. Confirm application ownership and access permissions.
    3. Contact an administrator if necessary.

    Session Expired

    The system redirects the user to the login page.

    Session Expired
    Possible Cause The user session timed out due to inactivity.
    Resolution 1. Log in again.
    2. Navigate back to the required page.
    3. Save work regularly to prevent data loss.

# External System Interfaces
This subsection identifies the external systems and services that may interact with the **CardFlow Credit Origination Platform** to support authentication, communication, data validation, and operational processing.

*External System Interfaces*

External System / Service | Purpose | Interaction Type
--- | --- | ---
Authentication Provider | Supports secure user authentication and identity validation. | Authentication / authorization
Email / SMS | Service	Delivers workflow-triggered notifications to applicants, reviewers, approvers, and administrators. | Notification delivery
Credit Bureau / External Credit System | Supports retrieval or validation of customer-related or credit-related information, where applicable. | Data lookup / validation
External API Consumers | Allows authorized external systems to create, retrieve, or update credit application data through secure APIs. | API integration
Reporting / Analytics Tools | May consume application, workflow, or audit data for operational reporting and monitoring. | Data export / reporting

# Environment Overview
The **CardFlow Credit Origination Platform** is deployed as a cloud-hosted, multi-tenant SaaS application accessible through supported web browsers. Users interact with the platform through web-based interfaces, while backend services process workflow actions, validation requests, approvals, notifications, reporting, and audit events.

*Environment Overview*
Environment Area | Description
--- | ---
**User Access** | Users access the platform through a browser-based interface.
**Web Layer** | Hosts the web application and user-facing interface components.
**Application Layer** | Hosts backend services such as workflow, validation, approval routing, reporting, and notifications.
**Data Layer** | Stores application records, workflow data, documents, audit logs, and configuration data.
**Integration Layer** | Supports communication with authentication services, notification providers, and external systems.
**Cloud Environment** | Provides hosting, scalability, availability, monitoring, and infrastructure support.

# Reviewing Recent Notification Activity
Users can review recent notification activity and previously generated notifications.
To review recent activity:
1.	Navigate to **Notifications**.
2.	Scroll to the **Recent Activity** section.
3.	Review recent workflow and system events.
4.	Open related records if additional information is required.

**Result**: Users can track recent notification activity and workflow events.

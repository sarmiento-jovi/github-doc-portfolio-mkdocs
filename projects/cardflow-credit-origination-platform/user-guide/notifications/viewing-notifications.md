# Viewing Notifications
Users can view notifications generated by workflow activities, approval actions, document events, and system processes.

To view notifications:
1.	Navigate to **Notifications**.
2.	Review the notification summary cards.
3.	Select the appropriate notification tab.
4.	Review notification details in the notification list.
5.	Select a notification to view additional information.

The **Notifications** page includes:
- **Notification** summary cards
- **Notification List**
- **Notification Details** panel
- **Notification Preferences** panel
- **Recent Activity** section

**Result**: Notification details are displayed and users can identify workflow activities requiring attention.

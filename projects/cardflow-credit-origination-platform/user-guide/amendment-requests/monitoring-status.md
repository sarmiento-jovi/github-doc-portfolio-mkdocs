# Monitoring Amendment Status
After submission, monitor the amendment request throughout the review and approval process.

To monitor amendment status:
1.	Navigate to **Applications > My Applications** or **My Requests**.
2.	Locate the amendment request.
3.	Review the current workflow status.

*Amendment Request Workflow Status*
Status|	Description
---|---
Draft |	Amendment request is being prepared and has not been submitted.
Submitted |	Request has been submitted for processing.
Under Review |	Request is being evaluated by a reviewer.
Pending Approval | Request is awaiting approver decision.
Approved |Amendment has been approved and applied.
Returned | Request requires correction or additional information.
Rejected | Amendment request has been rejected and no changes were applied.

4.	Open the request to view detailed status information, comments, and history.

    If a request is returned, review the comments provided, make the required updates, and resubmit the request.

**Result**: Users can track amendment progress and respond to review or approval feedback as needed.

# Docs-as-Code Publishing Workflow (GitHub + MkDocs) 

This topic discusses **Doc-as-Code** publishing workflow from converting the **MS Word** document to **Markdown** source files to rendering a public documentation website. 

1. **MS Word File**
- CCOP User Guide (Source Document) 
2. **Markdown Source Files (.md)**
- Manually convert the MS Word content
3. **GitHub Repository**  
- CardFlow Credit Origination-Platform documentation 
- Stores the Markdown source files, images, configuration files, and version history. 
4. **MkDocs** 
- Builds the static website from the Markdown source files. 
- Generates: 
  - Index.html 
  - Styles.css 
  - Javascript.js 
  - images/ ... 
5. **GitHub Pages** 
- Hosts the generated HTML website) 
- GitHub Pages is the hosting service. 
- The github.io URL is simply the address GitHub gives you. 
- Publishes the HTML website generated by MkDocs. 
6. **Public Documentation Website**
  
> https://sarmiento-jovi.github.io/cardflow-documentation

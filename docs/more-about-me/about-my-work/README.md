# About My Work

I am a Documentation Specialist with experience translating complex business and technical information into documentation that is structured, understandable, and useful to its intended audience.

My work extends beyond writing individual documents. I am interested in how information is structured, connected, maintained, visualized, and delivered throughout the software development lifecycle—from requirements and system design to user and developer documentation.

## How I Approach Documentation

I approach documentation by understanding the information before deciding how to present it. Whether I am documenting a business requirement, software workflow, system architecture, or user procedure, I first look at the underlying process, relationships, audience, and purpose.

From there, my goal is to determine the clearest way to communicate the information—through written documentation, structured content, diagrams, or a combination of these. This approach brings together technical analysis, information design, writing, and collaboration rather than treating documentation as an isolated writing task.

## Continuous Learning

I continuously develop my skills alongside the changing practices and technologies used in technical documentation.

My current work includes hands-on practice with Docs-as-Code using Markdown, Git, GitHub, and static-site documentation workflows. I am expanding this further into API documentation and documentation automation, with longer-term interests in structured, machine-readable content and AI-enabled documentation.

I use personal projects such as this portfolio to apply these concepts practically rather than learning them only in theory.

## Beyond Documentation

My interests in visual communication, photography, and technology influence how I think about information design and technical documentation.

I value clarity, structure, usability, and thoughtful visual presentation—principles that I apply across written documentation, diagrams, information architecture, and other forms of technical communication.

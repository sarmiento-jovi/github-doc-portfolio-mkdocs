# Authentication and Access Control
This subsection describes the authentication and authorization mechanisms used by the **CardFlow Credit Origination Platform** to control access to system resources and workflow operations.

The platform enforces **role-based access control (RBAC)** to ensure that users can only access functions, workflow actions, records, and administrative capabilities permitted by their assigned roles and tenant-specific permissions.

The security and access control architecture supports:

- User authentication and session management
- Role-based access control (RBAC)
- Tenant-level data isolation
- Permission-based workflow access
- Controlled administrative access
- Secure credential validation
- Authorization enforcement across workflow stages

The platform supports multiple user roles, including applicants, tenant users, reviewers, approvers, and administrators, each with distinct operational permissions and workflow responsibilities.

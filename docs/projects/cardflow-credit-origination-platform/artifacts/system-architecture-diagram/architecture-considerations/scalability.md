# Scalability
The platform architecture supports scalability by separating presentation, application processing, workflow orchestration, data management, and integration services into distinct architectural layers. This separation allows the platform to support increasing users, tenants, workflow transactions, and operational workloads without significantly impacting overall system behavior.

Scalability considerations include:

- Support for multiple tenant organizations
- Separation of processing services and data management
- Expandable workflow and approval processing
- Support for increasing workflow volumes and concurrent users
- Flexible integration capabilities for external systems and services

# Stakeholders and User Roles
This section discusses the primary stakeholders involved in the operation and use of the **CardFlow Credit Origination Platform**. These stakeholders represent the roles responsible for initiating:

- Credit applications
- Reviewing submitted information
- Approving or rejecting applications
- Managing system configuration and oversight

Understanding the responsibilities of each stakeholder group ensures the platform supports the operational workflows, approval hierarchies, and governance requirements associated with credit application processing.

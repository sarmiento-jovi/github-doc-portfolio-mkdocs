# Credit Application Processing
**Credit Application Processing** describes the steps required to create, complete, submit, and track credit applications in the **CardFlow Credit Origination Platform**. The workflow enables users to capture applicant information, provide supporting documentation, submit requests for review, and monitor application progress throughout the credit origination lifecycle.
